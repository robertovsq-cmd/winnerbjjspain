# Winner Behring Spain

Sitio de captación y SEO local para Winner Behring Spain en Barcelona.

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

El proyecto está preparado para desplegarse en Vercel sin configuración adicional.

## Antes de publicar

- Sustituir `34600000000` por el número real de WhatsApp en `app/ui.tsx` y `app/page.tsx`.
- Confirmar las direcciones y horarios de cada sede.
- Cambiar `winnerbjjspain.vercel.app` por el dominio definitivo en `app/layout.tsx`, `app/robots.ts` y `app/sitemap.ts`.
- Conectar Google Business Profile y añadir enlaces de Google Maps reales.

## SEO incluido

- Metadata, canonical, Open Graph y Twitter Card.
- Datos estructurados `SportsActivityLocation`.
- `robots.txt` y sitemap dinámico.
- Páginas de intención local para Barcelona, Gràcia, La Salut y Lesseps.
